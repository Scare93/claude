# Examples

This directory contains example usage scripts for the PDF to HTML Converter.

## Example Usage Script

The `example_usage.py` script demonstrates various ways to use the converter:

### Run All Examples

```bash
python example_usage.py
```

### Examples Included

1. **Basic Conversion**: Simple conversion with auto-generated output filename
2. **Custom Output**: Specify a custom output HTML filename
3. **Batch Conversion**: Convert all PDF files in a directory
4. **Metadata Access**: Extract and display PDF metadata

## Testing the Examples

To test the examples:

1. Place one or more PDF files in this directory
2. Run the example script:
   ```bash
   cd examples
   python example_usage.py
   ```

## Sample PDFs

You can download free sample PDFs for testing from:
- [PDF Sample Files](https://www.africau.edu/images/default/sample.pdf)
- Any PDF document you have available

## Expected Output

After running the examples, you'll see:
- Converted HTML files in the examples directory
- Console output showing the conversion progress
- Metadata information from the PDF files
